Apa itu cloud computing?

Cloud computing atau komputasi awan adalah model penyediaan sumber daya komputasi—seperti server, penyimpanan, database, jaringan, dan perangkat lunak—melalui jaringan sesuai kebutuhan. Pengguna dapat menyediakan dan mengelola sumber daya tersebut tanpa harus membeli serta mengoperasikan seluruh perangkat keras sendiri.

Istilah “cloud” bukan berarti data berada di udara. Layanan cloud berjalan di infrastruktur fisik, termasuk server dan data center yang dikelola penyedia atau organisasi.

Bagaimana cloud computing bekerja?

Penyedia cloud mengoperasikan kumpulan sumber daya komputasi di data center. Melalui portal, API, atau perangkat otomatisasi, pelanggan meminta kapasitas tertentu. Platform penyedia kemudian mengalokasikan sumber daya virtual atau layanan terkelola, mengatur jaringan dan penyimpanan, serta menyediakan mekanisme pemantauan dan penagihan.

Contohnya, pemilik aplikasi dapat membuat virtual machine, menghubungkannya ke database, menyimpan file pada object storage, dan mengatur aturan jaringan melalui dashboard. Kapasitas dapat dinaikkan atau diturunkan sesuai pola penggunaan, selama layanan dan konfigurasi mendukungnya.

Tiga model layanan cloud

Infrastructure as a Service (IaaS)

IaaS menyediakan komponen infrastruktur seperti mesin virtual, jaringan, dan penyimpanan. Pelanggan memiliki kontrol lebih besar atas sistem operasi dan konfigurasi aplikasi, tetapi juga bertanggung jawab mengelolanya.

Contoh penggunaan: menjalankan server aplikasi, lingkungan pengujian, atau sistem internal dengan konfigurasi khusus.

Platform as a Service (PaaS)

PaaS menyediakan platform untuk membangun dan menjalankan aplikasi tanpa pelanggan harus mengelola seluruh lapisan server. Penyedia menangani sebagian infrastruktur dan runtime, sementara pelanggan fokus pada kode, data, dan konfigurasi aplikasi.

Contoh penggunaan: deploy aplikasi web ke platform yang mengelola build, runtime, dan scaling.

Software as a Service (SaaS)

SaaS adalah aplikasi siap pakai yang diakses melalui browser atau aplikasi klien. Penyedia mengelola infrastruktur dan sebagian besar pemeliharaan aplikasi.

Contoh penggunaan: email bisnis, aplikasi kolaborasi, CRM, dan perangkat lunak akuntansi berbasis langganan.

Model deployment

  • Public cloud: layanan disediakan melalui infrastruktur penyedia untuk banyak pelanggan dengan isolasi logis.
  • Private cloud: lingkungan cloud digunakan secara khusus oleh satu organisasi.
  • Hybrid cloud: menggabungkan lingkungan private atau on-premises dengan public cloud.
  • Multi-cloud: menggunakan layanan dari lebih dari satu penyedia cloud.

Manfaat dan risiko cloud

Manfaat

  • Memulai layanan tanpa investasi awal besar untuk perangkat fisik.
  • Kapasitas lebih fleksibel mengikuti kebutuhan.
  • Akses ke layanan terkelola seperti database, analitik, dan AI.
  • Mempercepat eksperimen dan proses deployment.

Risiko dan hal yang perlu dikelola

  • Biaya: penggunaan yang tidak dipantau dapat menimbulkan tagihan tak terduga.
  • Keamanan: konfigurasi identitas, akses, jaringan, dan data tetap menjadi tanggung jawab pelanggan sesuai model layanan.
  • Ketergantungan vendor: layanan proprietary dapat membuat migrasi lebih sulit.
  • Ketersediaan: gangguan penyedia atau kesalahan konfigurasi dapat memengaruhi layanan.
  • Kepatuhan: lokasi penyimpanan dan pemrosesan data harus sesuai kewajiban organisasi.

Cara memilih layanan cloud

Mulai dari kebutuhan aplikasi, bukan dari nama penyedia. Tentukan pola trafik, kebutuhan database, sensitivitas data, target ketersediaan, kebutuhan backup, kemampuan tim, dan batas anggaran. Buat estimasi biaya berdasarkan komponen nyata—compute, storage, transfer data, database, log, backup, dan layanan tambahan.

Untuk aplikasi kecil, layanan terkelola dapat mengurangi beban operasional. Untuk sistem yang membutuhkan kontrol khusus, IaaS atau arsitektur hybrid mungkin lebih sesuai. Uji performa dan biaya menggunakan beban realistis sebelum memindahkan sistem penting.

Pertanyaan umum

Apakah cloud selalu lebih murah?

Tidak. Cloud dapat mengurangi biaya awal dan memberi fleksibilitas, tetapi total biaya bergantung pada pola penggunaan, arsitektur, transfer data, dukungan, dan pengelolaan.

Apakah cloud aman?

Keamanan bergantung pada penyedia, desain arsitektur, konfigurasi, dan pembagian tanggung jawab. Gunakan kontrol akses minimum, enkripsi, logging, backup, dan audit konfigurasi.

Apakah cloud dan data center berbeda?

Ya. Data center adalah fasilitas fisik. Cloud adalah cara sumber daya komputasi disediakan sebagai layanan. Infrastruktur cloud berjalan di data center.

Cloud bukan sekadar memindahkan server ke internet. Cloud mengubah cara organisasi menyediakan, mengelola, mengukur, dan membayar sumber daya teknologi.
